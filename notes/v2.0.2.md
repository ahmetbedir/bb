Dependency update release. No changes to how bb behaves.

## Security

All 15 `composer audit` advisories are fixed, among them a high-severity Guzzle host-check bypass (CVE-2026-69246) and a Proxy-Authorization header leak in the HTTP client that carries your Bitbucket token.

## Updated

- Laravel Zero 12 → **13** (Illuminate 13; desktop notifier 3 / JoliNotif 3)
- Saloon 4.0 → 4.5 and its Laravel plugin 4 → **5**
- Symfony 7.4.23, Guzzle 7.16

The release binaries bundle PHP 8.4 and are unaffected; running bb from source now needs PHP 8.3+.
