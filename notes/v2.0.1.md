## Fixes

- **Quieter `pipeline:watch`.** The "Showing the first N results; raise --limit" note now appears only when your own `--limit` cut a list short. It no longer shows up for bb's internal lookups such as finding the latest pipeline or deployment.
- **Notifications turned off? bb tells you.** If notifications for bb are off in System Settings, the next notification prints a hint on stderr: *System Settings > Notifications > bb*. Previously they failed silently.

## Docs

- Upgrade and uninstall with the full tap name (`brew upgrade ahmetbedir/tap/bb`): the short `bb` resolves to an unrelated Homebrew cask.
