Smaller, faster downloads. No changes to how bb behaves.

- **Release assets are compressed:** `.tar.gz` for macOS and Linux, `.zip` for Windows. Each download is about **15 MB instead of 35 MB**.
- Homebrew and the install scripts unpack them for you; nothing changes in how you install or upgrade:

```bash
brew upgrade ahmetbedir/tap/bb
# or
curl -fsSL https://github.com/ahmetbedir/bb/releases/latest/download/install.sh | sh
```

If you download a binary by hand, extract `bb` (or `bb.exe`) from the archive.
