bb 2.0 makes the CLI safe and efficient to drive from scripts and AI agents (Claude Code, Cursor, Codex, Copilot and others), and brings native desktop notifications on macOS.

## ⚠️ Breaking changes

Check your scripts and CI jobs before upgrading:

- **Errors and warnings go to stderr.** stdout carries only data. With `--json`, API errors are a JSON object on stderr: `{"error":{"status":404,"message":"..."}}`.
- **Piped tables are tab-separated**, with a header row and no colours or hyperlinks.
- **No silent defaults when nobody can answer a prompt.** Non-interactive runs (piped stdin, `-n`, or an AI agent) fail instead of assuming an answer. Pass `--yes` to confirm:
  - `pr:merge`, `pr:close`, `branch:delete`, `repo:delete`, `auth:logout`
  - `pipeline:run`, `pipeline:stop`, and `bb api` with any method other than GET
  - `repo:edit --public` and `plugin:install` always ask (or take `--yes`)
- **`--env` is no longer accepted.**

## Built for scripts and AI agents

- `--json` and `--jq` on write commands (`pr:create`, `pr:merge`, `pr:comment`, `issue:create`, `tag:create`, `branch:create`, `repo:create`, `pipeline:run` and more) and on `pr:status`. `--jq` on its own implies `--json`, and is validated before anything is sent.
- `BB_TOKEN` and `BB_WORKSPACE` authenticate without a config file. The token is never written to disk.
- AI agents are detected automatically and get non-interactive, undecorated output, even inside a pseudo-terminal. `BB_AGENT=0|1` overrides it.
- `bb api --paginate` follows every page; a note on stderr says when `--limit` cut a list short.
- **Agent skill:** `bb skill:install -g` installs the bb skill for every supported agent through [skills.sh](https://skills.sh), pinned to your bb version and refreshed automatically after upgrades. Agents that run bb without it get a one-time tip.

## Native macOS notifications

`pipeline:watch` and `pr:checks --watch` notifications now come from "bb" itself, with bb's icon, like any native app. On first use macOS asks whether bb may send notifications. Linux and Windows notifications go through Laravel Zero's notifier.

## Security and reliability

- Config writes are atomic, private (0600) and safe across concurrent bb processes. A damaged config file is never overwritten, so your token is not lost.
- OAuth: the `state` parameter is required, the callback server waits for the real redirect, and the redirect URI matches the documented `localhost` callback.
- Request paths with `.` or `..` segments are refused, pagination links are only followed on the API host, and the git credential helper answers only over HTTPS.
- `plugin:install` validates plugin names; `bb configure` exits 1 when Bitbucket rejects the token.

## Install / upgrade

```bash
brew upgrade ahmetbedir/tap/bb
```

Use the full name: Homebrew also has an unrelated `bb` cask.
